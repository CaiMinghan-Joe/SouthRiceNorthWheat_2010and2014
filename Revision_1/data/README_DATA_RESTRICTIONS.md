# Data restrictions

`HSSC_analysis_data_final.dta` is the analysis dataset corresponding to Revision 1 and is a local analytical derivative of China Family Panel Studies microdata. The CFPS Data User Agreement does not permit redistribution of original, partial, or modified CFPS datasets through journal websites or unauthorized third-party platforms. The file is intentionally absent from this public repository and must be excluded from any public or journal-submission archive unless explicit authorization is obtained from the CFPS project.

Authorized users should obtain CFPS data through the official CFPS platform, prepare the Revision 1 analysis dataset as authorized, and place it locally at `Revision_1/data/HSSC_analysis_data_final.dta`. Do not upload CFPS microdata or derived microdata to GitHub, external AI services, or other unauthorized platforms.

`historical_rice_province_data.xlsx` is a province-level external indicator workbook and contains no CFPS individual-level observations. Its provenance is documented in the package variable dictionary and README.
