# Data access

The former `SouthRiceNorthWheat_2010and2014.dta` file was removed from this public repository because it contains individual-level data derived from the China Family Panel Studies (CFPS).

Authorized users must obtain the underlying CFPS data from the official CFPS data platform:

https://cfpsdata.pku.edu.cn/#/home

Use the repository's legacy analysis code only with data that you are authorized to access and retain the data locally. Do not redistribute original, partial, or modified CFPS microdata through GitHub or other unauthorized third-party platforms.

For the Revision 1 replication materials, follow `Revision_1/data/README_DATA_RESTRICTIONS.md` and place the authorized local analysis file at `Revision_1/data/HSSC_analysis_data_final.dta`.
